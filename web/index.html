DATA & MODEL BOUNDARY

看见完整过程，区分真实与模拟

道路、建筑轮廓与水域/绿地来自 OpenStreetMap。建筑高度优先使用 OSM 高度或层数；缺失高度使用示意值，不代表测绘精度。

  • 车辆位置、车速、路口相位由实际运行的 SUMO 提供。
  • RSU 的位置、覆盖、计算资源与任务时延是本演示的配置。
  • 声学任务由车辆经过事件触发，采用模拟感知结果；没有执行真实录音的神经网络识别。
  • 流动数据包、回传与节点状态跟随后端任务时间戳；道路标签与建筑立体外观只服务于观察。
  • 信号计划与控制策略是仿真配置，不是当地市政实测配时。完成的任务结果才可以进入信号决策，决策也可能被约束拒绝。
  • 跟车功能按车辆 ID 展示该车任务。一个车辆可能产生多项任务；信号响应仍由后端控制约束决定。

本页面用于软件流程与可行性演示，不能据此推断真实声学精度或实际交通改善幅度。
